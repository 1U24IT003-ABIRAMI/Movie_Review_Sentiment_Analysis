# 🎬 Movie Review Sentiment Analysis

**Overview:**
An NLP-based project that classifies movie reviews as **Positive 😊 or Negative 😞**.

**Technologies:** Python, Word2Vec, Sentence Transformers, Random Forest, TensorFlow, Scikit-learn.

**Models:**

* Word2Vec + Random Forest
* 🏆 **Sentence Transformer + Random Forest**
* Word2Vec + Neural Network
* Sentence Transformer + Neural Network

**Best Model:** 🏆 **Sentence Transformer + Random Forest**
**Test Accuracy:** **72.81%** 

**Conclusion:**
The project successfully analyzes movie reviews and predicts audience sentiment using NLP and Machine Learning.
